# הגנה בפני חשמול – תוכנה לימודית

תוכנה לימודית בעברית (RTL) עם שבעה מודולים אינטראקטיביים לשיטות ההגנה בפני חשמול:
1. הארקת הגנה 2. איפוס 3. מפסק מגן (פחת) 4. שנאי הפרדה 5. בידוד כפול/מוגן 6. מתח נמוך במיוחד (SELV/PELV) 7. שוות פוטנציאל / מקום מבודד.

## הרצה
אין צורך בהתקנה: פתחו את `index.html` בדפדפן, או הגישו את התיקייה כאתר סטטי (`python3 -m http.server`).

## הערה חשובה
התוכנה נועדה להמחשה בלבד. המודלים הפיזיקליים מפושטים, והערכים (50V/25V, 30mA, זמני ניתוק וכו׳) הם כפי שמקובל בחומר הלימוד – **יש לאמת אותם מול נוסח חוק החשמל, התקנות והתקנים התקפים** לפני כל שימוש מקצועי.
